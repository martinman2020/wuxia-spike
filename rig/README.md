# Spike 004 — 2D 角色動作演出（骨架拼貼）

**問題（spike 想答嘅）**：一人 + AI，做唔做到「角色真係做出攻擊動作」嘅演出（類似《卡厄思夢境》嘅打擊感）？
上一輪已實測：**逐格 sprite animation 唔可行**（AI 圖生圖跨格唔一致，服裝會自己加減）。
所以本 spike 測第二條路：**由單一張角色圖裁部件 → 依骨架樞軸旋轉 → 演出層**。

## 做法

1. AI 生成**一張**基準姿勢（側面朝右、四肢分開、劍前伸）→ 同源就一定同風格、同比例。
2. 用視覺分析定位關節（頸 19%、腰 39%、肩 46% 寬 / 20% 高），切成 4 塊：
   `head` / `torso` / `arm_front`（含劍）/ `legs`。
3. 部件轉成「**墨色 + alpha**」圖層（用墨覆白紙嘅物理模型反算 alpha = (255−L)/(255−26)），
   否則旋轉時會拖住一塊白底遮住身體。
4. 依樞軸做 CSS `rotate` keyframes：收招 → 出劍 → 命中定格 → 收勢（0.95s）。
5. 加上演出層：白閃衝擊幀、墨點粒子、傷害數字、假人受擊位移、殘像。

## 驗證（全部可重跑）

```bash
python3 build-parts.py   # 下載 AI 部件圖（第一版失敗做法，保留做記錄）
python3 cut-parts.py     # 裁切 + 兩項自動驗證 + PIL 實 render 兩個姿勢
```

| 驗證 | 方法 | 結果 |
|---|---|---|
| 靜止姿勢還原 | 部件按 z 序疊返 vs 原圖逐像素 diff | 差 >12 嘅像素 **10.8%**，全部落在裁切框邊界同重疊帶（雙重疊墨） |
| 墨跡有無流失 | 差異熱區圖 + 視覺核對 | 檢查確認：**無任何墨跡丟失或重複**，整體濃度同原圖一致 |
| 關節有無崩 | PIL 實 render 收招／出劍兩個姿勢 → 視覺核對 | 頸、腰、肩連接連續，無斷肢、無殘留墨塊 |

姿勢對照圖：`assets/poses.png`（左：收招蓄勢｜右：出劍命中）

## 結論

**可行，但係「有限動作」而唔係「手繪動畫」。**

能力：
- 收招 → 出劍 → 定格 → 收勢，四個節奏靠一條 keyframes 描述，調整只改角度，唔用重畫
- 加殘像、衝擊幀、粒子、鏡頭撲前 → 打擊感主要來自呢層（實測姿勢本身無崩，所以演出層可以放心加）
- 同一套 rig，換 keyframes 就出第二招（例如橫掃＝手臂由 −60° 掃到 +40°）

限制（唔可以扮冇）：
- 只會旋轉，**做唔到重心轉移、步法、劍弧線**；單一基準姿勢 → 所有招式共用同一個站姿
- 彎喺胸前嘅左手屬軀幹圖層，**永遠唔會動**
- 前後遮擋係假嘅（靠 z-index 硬排）
- 每個新角色要重新生成基準圖 + 重新定位樞軸（人手，AI 幫唔到）

## 真實成本（一人實測，唔係估）

| 項目 | 實測 |
|---|---|
| 建立這套 rig 系統（含兩次失敗方向） | 一個工作 session |
| 一個角色：生成基準圖 + 定裁切線 + 定樞軸 | 約 1–2 小時（要視覺核對幾輪） |
| 每加一招（同一角色，改 keyframes） | 約 30–60 分鐘 |
| 每個新角色 | 約 3–5 小時 |
| 對比：手繪逐格（6–12 格 × 9 招） | 每角色 **54–108 張圖**，每張都要風格一致 → 一人唔可行 |
